# File friction

File recurring friction with a clear owner and a reproducible problem. Skip
one-off confusion. See the
[filing policy](../../../docs/contributing/friction-log.md#when-to-file) and
[choose the target](../../../docs/contributing/friction-log.md#where-it-belongs).

Use the
[hosted CLI command](../../../docs/contributing/friction-log.md#file-an-entry)
to run `kody:@kody/kody-factory/friction/file` with `target` and `items`.
